# Presentation Deck Template — 発見駆動型プレゼン・登壇台本

登壇・カンファレンス・社内発表など、参加者の発言を前提としない一方向のプレゼンに使用するテンプレート。ワークショップと違い、聴衆との対話は最小限。代わりに「**聴衆の頭の中で**点と点を線にする」設計に集中する。

## 構造

```markdown
# [プレゼンタイトル]

## メタ情報
- 目的（聴衆に何を持ち帰ってもらうか）:
- 聴衆（カンファレンス参加者像、前提知識、競合する関心事）:
- 立ち上げたい結論（書かない・最後に聴衆の中に立ち上がってほしい1文）:
- 持ち時間:
- 配置する点の数:

## 全体の地図

冒頭で「今日話す3つのこと」のような構造予告は**しない**。代わりに、最初の点で違和感を作って引き込む。

## スライド/セクション構成

### スライド1: つかみの違和感

**スライドに表示するもの**:
**口頭で語ること**:
**口頭で語らないこと**:
**演技指示**:
- 自己紹介から入らない。最初に違和感を投げてから自己紹介する
- 「今日は○○についてお話しします」と言わない
**所要時間**:

---

### スライド2-N: 点の配置

各スライドに以下の構造を適用する：

#### スライドX: [点の名前]

**スライドに表示するもの**: [画像/図/短いフレーズ。情報を詰め込まない]
**口頭で語ること**:
**口頭で語らないこと**:
**演技指示**:
- スライドを表示してから、最低3秒は黙る（聴衆に見させる時間）
- 重要なフレーズは2回繰り返す
**所要時間**:

---

### 接続スライド（点と点の間に挟む）

スライドに表示するのは「問いだけ」のスライド。一行だけ。

例：
- 「で、この2つ、何が共通してると思います?」
- 「ここで、ひとつ問題があります」
- 「不思議じゃないですか?」

**演技指示**:
- このスライドは10秒〜20秒、何も話さずに表示する
- 聴衆の頭の中で線が動く時間を作る

---

### 終盤の収束スライド

**スライドに表示するもの**: 全ての点を1枚に集約した図（ただし**線は引かない**）
**口頭で語ること**: 聴衆の頭の中で線が引かれていることを確認する。「ここまでで、皆さんの中に何か繋がってきたかもしれません」
**口頭で語らないこと**: 結論そのもの
**演技指示**:
- 言い切らない
- 余韻で終わる

---

## 意図的な穴

意図的な穴は登壇では「セルフ突っ込み」の形で実装する。
聴衆が抱きそうな反論・疑問を、自分から先に口にする。

| 項目 | 内容 |
|---|---|
| 穴（聴衆が抱きそうな疑問） | |
| いつ自分から触れるか（スライド番号） | |
| どう触れるか | 「ここで、こう思った方もいるかもしれません。『○○じゃないの?』と」 |
| 回答 | |

## 終わりの余韻

- 「ご清聴ありがとうございました」で終わらない
- 最後のスライドは「持ち帰り用の問い」または「未解決の余韻」
- 質疑応答に繋がる形で開いて終わる

## 質疑応答の準備

| 想定質問 | 回答の方向性 |
|---|---|
| | |

質疑応答は意図的な穴の延長戦。プレゼン中に作った穴に対する質問が必ず来るので、その回答を磨いておく。

## 演技指示の総則（登壇版）

- スライドより聴衆を見る
- 沈黙の威力を信じる（特に問いの後）
- 自分が緊張していても、聴衆の方が緊張していると思って話す
- スライドに書いてあることを読み上げない（聴衆も読める）
- 重要なフレーズは繰り返す（一度では届かない）
```

## 使い方

1. メタ情報を埋める
2. 立ち上げたい結論を1文で確定する（書かない）
3. 点を3〜5個抽出し、意外性のある順序で並べる
4. 各スライドの「表示するもの」と「口頭で語ること」を分離する
5. 接続スライド（問いだけのスライド）を点と点の間に挟む
6. 意図的な穴を最低1つ設計する（セルフ突っ込みの形）
7. 生成後、`SKILL.md` のアンチパターン表で自己チェックする
