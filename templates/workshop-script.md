# Workshop Script Template — 発見駆動型ワークショップ台本

ワークショップ台本生成時に使用するテンプレート。`SKILL.md` の中核原理に従って、参加者の発見体験を最大化する構成を組む。

## 構造

```markdown
# [ワークショップタイトル]

## メタ情報
- 目的（参加者に何を持ち帰ってもらうか）:
- 聴衆（参加者プロフィール、前提知識、想定される抵抗・バイアス）:
- 立ち上げたい結論（書かない・最後に参加者の中に立ち上がってほしい1文）:
- 持ち時間:
- 配置する点の数:

## セクション構成

### セクション1: 違和感の提示（導入の点①）

**配置する点**: [事実・データ・違和感・対比・問いの形のいずれか]
**何を見せる/言う**:
**何を言わない**:
**演技指示**:
- 問いの後、最低___秒は黙る
- [その他、視線・身振り・間の取り方の指示]
**所要時間**:

---

### セクション2: 一見無関係なエピソード（点②）

**配置する点**:
**何を見せる/言う**:
**何を言わない（特に、点①との関連は明示しない）**:
**演技指示**:
**所要時間**:

---

### セクション3: 接続の問い

**問い**: 「この2つ、何か繋がっていると思いません?」「もし関係があるとしたら、どんな関係?」
**想定される反応の3パターン**:
1. [パターンA]
2. [パターンB]
3. [パターンC]
**各反応への返し方**:
- A → [復唱+深堀り]
- B → [復唱+別の点に橋渡し]
- C → [復唱+保留]
**演技指示**:
- 最初に発言した参加者の言葉を必ず復唱する
- 復唱の後、「他にもありますか?」を1回だけ挟む
- 全員に意見を求めない（言いたい人だけ）
**所要時間**:

---

### セクション4: 第三の点（点③）

**配置する点**: ※点①と②の線が繋がる「橋」となる点
**何を見せる/言う**:
**何を言わない**:
**演技指示**:
**所要時間**:

---

### セクション5: 発見の余韻

**何をするか**: 参加者の発見を整理して見せる（言語化を支援する）。ただし「正解」として与えない
**フレーズ例**:
- 「皆さんの中で○○という言葉が出てきましたね」
- 「これって、つまり○○ということかもしれませんね」(「かもしれません」が重要)
**演技指示**:
- 結論を言い切らない
- 参加者の言葉で言い直す
**所要時間**:

---

## 意図的な穴

| 項目 | 内容 |
|---|---|
| 穴 | [明らかに不完全に見える図・数字・例] |
| なぜ穴を作るか | [何を質問させたいか] |
| 想定質問 | |
| 回答ストック | |
| 回答で立ち上がる本筋 | |

## 終わりの余韻

- 持ち帰ってもらう「最後の点」: [問いの形で残す。「皆さん、明日からこれを考えてみてください」のような]
- 締めない、開いたまま終わる

## 想定Q&A（穴以外の想定質問）

| 質問 | 回答の方向性 |
|---|---|
| | |

## 演技指示の総則

- 沈黙を恐れない。問いの後の沈黙は思考時間
- 参加者の言葉を必ず復唱する。これだけで「聞いてもらえた」感が生まれる
- 自分の意見を急いで言わない。参加者の発見を待つ
- 「正解」を持っているように見せない（持っていても）
- スライドより人を見る
```

## 使い方

1. ワークショップの依頼を受けたら、メタ情報の4項目を埋める
2. 立ち上げたい結論を1文で確定する（書かない）
3. その結論を支える点を3〜5個抽出する
4. 点を意外性のある順序で並べる
5. テンプレに従って各セクションを埋める
6. 意図的な穴を最低1つ設計する
7. 生成後、`SKILL.md` のアンチパターン表で自己チェックする
